# R6: Daily games and sharing (phase 6)

Branch `phase-6-daily`, verified 2026-11-12 (Asia/Dhaka). The agent released it under D2b.

## Epoch

`DAILY_EPOCH = '2026-11-12'`, the publication date, so puzzle #1 is 12 November 2026 in the visitor's local calendar. It is identical in all four daily apps (`src/lib/daily.ts`, checked by `sync-shared --check --set daily`) and in `homepage/daily.js` (parity test). `tests/daily-release.test.ts` now always runs and fails if the placeholder returns. Never change the epoch after release: it renumbers every puzzle.

## Changes

- **Shared daily module (T6.1):**
  - Local-date day number, seeded permutation selection and streaks.
  - Plain share text with a WhatsApp link, ending in the app's own host.
  - A `.ics` "Remind me daily" builder (`dailyReminderIcs`, T6.7).
  - Identical copies in the four daily apps.
- **Guess the Surah (T6.2):**
  - Daily, Practice and Juz tabs. Juz membership comes from verified Quran MCP metadata.
  - The chapter-number clue is replaced by the verified name meaning (C1, 114/114), shown with its source.
  - An "Arabic first" toggle, a local 114 collection, the descriptor "A daily Quran quiz: find the surah from its clues" and the chip "114 surahs".
- **Ayah Threads (T6.3, C2):**
  - All 30 puzzles draw from at least two surahs (28 use three), and no ayah appears in two puzzles.
  - Distractors are real bank themes, each used three times, with a near-synonym blocklist.
  - Daily and Practice, solved ticks in the picker, and a link to the theme library after a solve.
- **Word Groups (T6.4, C3):**
  - 45 groups and 30 boards with distinct titles.
  - Tiers 1–4, shown with text labels, and an `incompatible` list so that no board has a second valid solution.
  - Daily with a four-mistake limit, a result card and a 30-pill board picker.
- **Seerah Timeline (T6.5, C10):**
  - A daily "Which came first?" from 31 verified pairs.
  - One pick reveals both events' dates (approximate where they are approximate), sources and date notes.
- **Reminders (T6.7):** a "Remind me daily" calendar file in all four daily apps. It is built in the browser and nothing is sent.
- **Directory (T6.6):**
  - "Tonight on Moongazer" tiles, Guess the Surah #N and Word Groups #N.
  - An Ayah of the night card (C18, 66 verified ayat) with exact Arabic in an Amiri subset, Pickthall's translation and a link to the reference in Is It in the Quran?.
  - On phones the ayah is a one-line summary that opens on tap.
- **Booktube feed (T6.8):**
  - `moongazer.tech/daily/booktube.json` covers the next 60 days, built from each app's own daily bank.
  - It is served with noindex and is not linked.
- **Privacy:** the page names the daily result and the opt-in streak.
- **Descriptors:** the directory and SEO catalog descriptors match the apps.
