# Family Islamic Learning Challenges

Choose a short pack, gather around, and learn something together.

Independent Astro 7.4.2 / Bun 1.4.4 project.

```sh
bun install --frozen-lockfile
bun run dev
bun run check
bun test
bun run build
bun run preview
```

Port 4339. Cloudflare Pages project root `apps/family-islamic-learning-challenges`, output `dist`, build `bun install --frozen-lockfile && bun run build`, environment `BUN_VERSION=1.4.4`. Host at the domain root. No adapter, secrets, backend or live content API.

12 single-sitting packs, each with a reading question, discussion and shared activity. Age/topic/type filters, print, optional recovery and completion sharing.

Suggested age bands are editorial reading guidance, not developmental assessments. Collect no names, child profiles, private disclosures or ongoing progress history.

Read AGENTS.md and context/ before implementation. Sources and privacy pages explain content editions, reuse and temporary optional localStorage. Release ZIPs are produced at repository level.
