# Halal Business Decisions

Work through fictional business dilemmas, then inspect the choices and sources.

Independent Astro 7.4.2 / Bun 1.4.4 project.

```sh
bun install --frozen-lockfile
bun run dev
bun run check
bun test
bun run build
bun run preview
```

Port 4337. Cloudflare Pages project root `apps/halal-business-decisions`, output `dist`, build `bun install --frozen-lockfile && bun run build`, environment `BUN_VERSION=1.4.4`. Host at the domain root. No adapter, secrets, backend or live content API.

12 fictional two-stage cases about disclosure, contracts, fair measures, payment and trust. Branch-specific consequences, source readings and optional recovery.

Educational applied reasoning does not constitute a scholarly ruling or opinion from quran.ai, quran.com or quran.foundation. No personalized legal or financial advice.

Read AGENTS.md and context/ before implementation. Sources and privacy pages explain content editions, reuse and temporary optional localStorage. Release ZIPs are produced at repository level.
