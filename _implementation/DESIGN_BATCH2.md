# Design decisions for apps 6–10

Continue the first batch's quiet reading interface: white/cool-gray surfaces (#f5f8fa, #ffffff), navy text (#172a35), teal (#087f75), blue (#316caa), and violet (#7255a0). Dark mode uses navy surfaces and pale accents. Keep DM Sans for controls and body text, Newsreader available for editorial moments, and Amiri for canonical Arabic. All fonts are local.

Each app has a different main interaction rather than a generic dashboard. The planner uses a revision curve and an exact schedule; the checker opens directly into a search field; the atlas connects a focused reading to neighboring themes; the rooms reveal four sequential locks; the prophets library opens into an alphabetical reading shelf. Titles describe the visitor's next action. The source shelf is visible without an account or saved progress.

The shared shell keeps theme, privacy, source notes, and clear-data controls in predictable places. Long product names wrap within the mobile header. Layouts use three-column shelves, two-column shelves at medium widths, and one column on narrow screens. Text, native form controls, and ordering buttons provide alternatives to visual interactions. Reduced-motion preferences disable nonessential transitions.

The source text carries the visual weight. Avoid portraits of prophets, decorative fake Arabic, and invented map coordinates. Brief Quran mentions stay brief. Separate canonical text from editorial reading titles, matching questions, and calculator assumptions.
